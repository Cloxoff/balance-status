# 🤖 FazerCards Price Tracker

Полностью автономный Telegram-бот для мониторинга оптовых цен поставщика **FazerCards** в режиме реального времени.

Скрипт работает независимо, не требует баз данных (PostgreSQL/MySQL/SQLite), не привязан к магазинам или заказам и хранит историю базовых цен в локальном файле `prices_cache.json`.

---

## ⚡ Основные возможности

* **Круглосуточный мониторинг:** Проверка оптовых цен FazerCards через заданный интервал (`CHECK_INTERVAL`).
* **Красивые уведомления:**
  * 📈 **Подорожание** с указанием старой и новой цены, прироста в `+$` и `+%`.
  * 📉 **Снижение цены** с расчетом экономии в `-$` и `-%`.
* **Умная пороговая фильтрация (`MIN_DIFF`):** Оповещения отправляются только при изменении цены на величину $\ge$ порогу (например, от `$0.05`). Мелкие колебания цен (например, `+$0.02`, затем `+$0.03`) накапливаются в кэше, пока суммарная разница не достигнет порога.
* **Надежное кэширование:** Базовая цена в локальном кэше `prices_cache.json` обновляется **только после успешной отправки уведомления**. Если связь прервалась — бот повторит попытку в следующем цикле.
* **Ручные команды в Telegram:**
  * `/prices` — моментальный запрос актуального прайс-листа по всем отслеживаемым товарам.
  * `/check` — принудительный запуск цикла проверки цен прямо сейчас.
  * `/status` — просмотр настроек трекера (интервал, порог, фильтры, время последней проверки).
  * `/help` — справка по командам.
* **Гибкая фильтрация по играм (`FILTER_KEYWORDS`):** Можно отслеживать конкретные игры (например, `PUBG,Mobile Legends`) или оставить поле пустым для отслеживания всех доступных товаров каталога.
* **Безопасность:** Доступ к командам бота имеют только указанные в `CHAT_ID` пользователи.

## 🚀 Быстрый старт на Linux сервере (Ubuntu / Debian VPS)

### Шаг 1. Распаковка архива
Скопируйте архив `fazercards_tracker.zip` на ваш сервер и распакуйте его:
```bash
# Установите unzip, если он не установлен
sudo apt-get update && sudo apt-get install -y unzip python3 python3-venv python3-pip

# Распакуйте в директорию /opt/fazercards_tracker
sudo unzip -o /root/fazercards_tracker.zip -d /opt/
cd /opt/fazercards_tracker
```

### Шаг 2. Создание виртуального окружения и установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 3. Настройка файла конфигурации (.env)
Создайте рабочий файл `.env` из шаблона:
```bash
cp .env.example .env
nano .env
```

Заполните переменные:
* `BOT_TOKEN` — токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).
* `CHAT_ID` — ваш Telegram ID (узнать можно у бота [@userinfobot](https://t.me/userinfobot)). Можно указать несколько через запятую: `123456789,987654321`.
* `FAZERCARDS_API_KEY` — ваш API-ключ от FazerCards.
* `FAZERCARDS_API_URL` — ссылка на ваш MCP-эндпоинт FazerCards (вида `https://api.fzr.cards/mcp/ВАШ_SLUG`).
* `MIN_DIFF` — минимальный порог изменения цены в долларах для отправки уведомления (по умолчанию `0.05`).
* `CHECK_INTERVAL` — интервал между проверками в секундах (по умолчанию `60`).
* `FILTER_KEYWORDS` — названия игр через запятую (например, `PUBG,Mobile Legends`). Если оставить пустым — будут отслеживаться все доступные позиции.

Сохраните файл (`Ctrl+O`, затем `Enter`) и закройте редактор (`Ctrl+X`).

### Шаг 4. Проверка работоспособности
Отправьте тестовое сообщение в Telegram, чтобы убедиться в правильности токена и ID чата:
```bash
python main.py --test-alert
```
Если сообщение пришло в Telegram, выполните тестовую проверку цен:
```bash
python main.py --check-now
```

### Шаг 5. Настройка автозапуска через systemd (24/7 в фоне)
Чтобы скрипт работал непрерывно и автоматически запускался при перезагрузке сервера:
```bash
# Копируем файл службы в systemd
sudo cp fazercards_tracker.service /etc/systemd/system/

# Перезагружаем конфигурацию systemd и запускаем службу
sudo systemctl daemon-reload
sudo systemctl enable --now fazercards_tracker

# Проверяем статус службы
sudo systemctl status fazercards_tracker
```

**Полезные команды для управления службой:**
```bash
sudo systemctl restart fazercards_tracker   # Перезапуск службы
sudo systemctl stop fazercards_tracker      # Остановка службы
journalctl -u fazercards_tracker -f        # Просмотр логов в реальном времени
```

## 💻 Запуск на локальном ПК (Windows / macOS)

### Шаг 1. Установка Python
Убедитесь, что установлен Python версии 3.9 или выше. Скачать можно с официального сайта [python.org](https://www.python.org/).

### Шаг 2. Установка зависимостей
Откройте терминал (PowerShell или Командную строку) в папке с проектом:
```powershell
# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows PowerShell):
.\venv\Scripts\Activate.ps1

# Установка библиотек:
pip install -r requirements.txt
```

### Шаг 3. Настройка .env
Скопируйте `.env.example` в `.env` и впишите ваши ключи.

### Шаг 4. Запуск трекера
```powershell
python main.py
```

## 🛠️ CLI команды для ручного управления

* `python main.py` — обычный запуск Telegram-бота и фонового мониторинга.
* `python main.py --check-now` — однократный опрос FazerCards без входа в цикл ожидания (удобно для проверки работы API).
* `python main.py --test-alert` — отправка тестового оповещения в Telegram для проверки связи.
* `python main.py --reset-cache` — удаление локального файла `prices_cache.json` (при следующем запуске кэш будет пересоздан заново).
